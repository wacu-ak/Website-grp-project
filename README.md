# My Portfolio Website

A single-page personal portfolio built with plain HTML, CSS and JavaScript.

## Sections
- Header / navigation
- Testimonials (rendered with JavaScript from an object, using a loop)
- Projects (rendered with JavaScript)
- Contact

## Files
- `index.html` - page structure
- `style.css` - all styling (includes a mobile layout)
- `script.js` - testimonial and project data, plus the code that shows them

## How to run
Open `index.html` in your browser.

## How to customise
1. Replace "Your Name", the email and the GitHub link in `index.html`.
2. Edit the `testimonials` object and `projects` array in `script.js`.
